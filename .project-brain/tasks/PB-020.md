   Cihaz: `emulator-5554`. Kanıt: `adb devices -l`, `getprop ro.build.version.sdk`.
2. Çevrimdışı yap: `settings put global airplane_mode_on 1`, `svc wifi disable`,
   `svc data disable`. Kanıt: `airplane_mode_on=1`, `Wi-Fi is disabled`,
   `mDataConnectionState=0`, `ping 8.8.8.8` → "Network is unreachable".
3. Otomatik akış: `flutter drive --driver=test_driver/integration_test.dart
   --target=integration_test/dod_flow_test.dart -d emulator-5554`
   (onboarding → Bugün → ölçüm 90/2,5 → GKI 2,0 → Günlük).
4. Taze kurulum yürüyüşü: test derlemesini kaldır, release APK'yı kur
   (`adb uninstall` + `install -r app-release.apk`), uygulamayı aç.
5. 11 adımı uçak modunda yürü, her adımda ekran görüntüsü al:
   `adb exec-out screencap -p > docs/evidence/screenshots/1.0.0+4/<ad>.png`
