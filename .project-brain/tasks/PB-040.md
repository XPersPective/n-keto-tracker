## Objective
Prepare the first App Store iOS candidate using GitHub Actions. Preserve the existing Android package and offline, ad-free, purchase-free, encrypted health-data architecture.

## Steps
1. Align the iOS Runner app bundle ID with the existing publishing registry, com.crazypenguin.nketotracker.
2. Add a manual macOS release build through GitHub Actions with App Store signing, exact source, build metadata checks, an unsigned validation option, and optional upload to App Store Connect.
3. Check the native build and signing. Retain the upload evidence and keep the App Store record and export compliance open until confirmed.

4. Run the existing store UI harness on large iPhone and iPad simulators and capture native Apple screenshots in English and Turkish.

5. Publish the existing local-data privacy policy at a stable URL for Apple and stage the en-US/tr listing fields.
