# User Guide — N Keto Tracker

## Getting started
Open the app; the 8-step onboarding can be completed or skipped.

## Quick actions (Today tab)
Measurement, meal, weight, symptom — each opens with at most 3 taps.

## Log
Timeline, separate small charts (GKI, glucose, ketone), research bands
off by default with source links available.

## Plan
Weekly plan generated deterministically, recipes, shopping list aggregation.

## Guide
Keto basics, evidence layers, disease-specific research only when you
explicitly opt into that section.
