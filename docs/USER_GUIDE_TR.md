# Kullanıcı Kılavuzu — N Keto Tracker (TR)

## Başlangıç
Uygulamayı açın; 8 adımlı Giriş sizsiz bilinci hedefiyle atlayabilirsiniz.

## Hızlı eylemler (Bugün sekmesi)
Ölçüm/yemekyapma/ağırlık/semptom — her biri tek dokunuşla başlatılır.

## Günlük
Tüketim çizelge, ayrı küçük grafikler (GKI, glukoz, keton), araştırma
katmanları varsayılan olarak kapalı ve kaynaklıdır.

## Plan
Haftalık plan üretir, tariflerden seçer, alışveriş listesi oluşturur.
Deterministik; ağ yok.

## Rehber
Keto temelleri, kanıt katmanları, hastalığa özel araştırmalar yalnızca
istediğinizde görünür.
